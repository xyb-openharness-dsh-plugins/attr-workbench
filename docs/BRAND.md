# 品牌：小甲宝 / ATTR-Pal

定名日期：2026-10-21（当日第三次定名）　状态：**产品名与形象均已定，副标题定位待用户确认**

命名沿革：小淀宝 / AmyPal → 淀粉宝宝 / ATTR-Pal → **小甲宝 / ATTR-Pal**（用户 2026-10-21 决定）。仓库名与包名始终为 `attr-workbench`，不随品牌改名。

## 1. 名字

| 项 | 值 | 说明 |
| --- | --- | --- |
| 中文 | **小甲宝** | 三字格，与家族一致；「甲」取自**转甲状腺素蛋白**（见下） |
| 英文 | **ATTR-Pal** | Pal = 伙伴；比 "assistant" 轻，适合长期记录工具 |
| 曾用 | 淀粉宝宝 / ATTR-Pal | 2026-10-21 上午使用；取自病友自称「淀粉人」 |
| 曾用 | 小淀宝 / AmyPal | 最早方案；「淀」= 淀粉样蛋白沉积 |
| 仓库/包名 | `attr-workbench` / `@xyb-community/attr-workbench` | **不随品牌改名**，避免破坏装机与既有链接 |

### 「甲」的锚点

ATTR 全称「转甲状腺素蛋白淀粉样变性」，前四字是**转甲状腺素蛋白（transthyretin, TTR）**。「甲」取甲状腺素，是患者与家属最熟悉的那半个词根——比「淀」通俗，比「淀粉」少一个字，比「A」有实际含义。

### 保留意见（写下来，不藏）

这一条是设计侧的真实顾虑，不影响当前定名，但**任何对外材料都不许删掉它**：

1. **ATTR 不是甲状腺疾病**。TTR 是甲状腺素和视黄醇的转运蛋白，由**肝细胞**合成，病变在蛋白错误折叠与沉积，不在甲状腺本身。叫「甲宝」会把品牌往内分泌科方向带，而 ATTR 患者实际分散在心内科、神经内科、血液科、肾内科，极少首诊内分泌科。
   - **对冲办法**：凡出现「小甲宝」的场合，副标题或首句必须同时给出全称「转甲状腺素蛋白淀粉样变性」。品牌名永远不单独成句。
2. **「甲」的日常第一义是指甲**。检索「甲宝」得到的是美甲配件（美康雅 CPN1）、广东甲宝输送机械、动画《铁甲小宝》、趾甲剪刀——即「甲宝」一词已被美甲与五金占用。
   - **对冲办法**：品牌名不做检索入口，对外传播主关键词恒为「ATTR」「淀粉样变性」「心肌淀粉样变」「转甲状腺素蛋白」。

### 已弃用方案的风险记录（备查）

- 「淀粉宝宝」：被幼儿园课程《你好！淀粉宝宝》与婴儿辅食问答《淀粉宝宝可以吃吗》占满，自然流量为零，易被误解为母婴内容。
- 「小A宝」：**「A友」是艾滋病感染者社群既有的自称**（A = AIDS；中国新闻网 2013 年报道直接写「'A友'就是艾滋病友的意思」，多地疾控「艾友会」活动一律简称「A友」）。做成「小A宝」会被读成 HIV 相关形象，**永久弃用**。
- 「小A宝」的第二个问题：A 是字母不是汉字，家族其他工作台的「X」各有医学或病种群锚点（畅、咽、肺、胰、吉），字母的锚点为零，且中文里完全不可检索。

### 年龄错位

ATTR 患者以 60 岁以上为主（野生型尤甚），"宝宝"对这部分人可能显得幼稚。缓冲办法：UI 里品牌只出现在侧栏与页脚，不进入提示语、按钮、表单，**不出现"宝宝帮你……"这类拟人句**。

## 3. 形象（当前版本）

**已采用用户提供的外部参考稿**（2026-10-21 决定，源图留档 `raw-ref-jiabao-2026-10-21.png`）。

- 奶油色圆润角色，白脸，两点眼 + 一个笑，有腮红，右手举起。
- 身上缠**金色丝带**：对应 ATTR 的病理核心——错误折叠的 TTR 聚合成**不溶性淀粉样纤维**并沉积。这是本形象最重要的医学锚点。
- 身缠一条青色带，右下手持**盾牌**（内为人形 + 心）。
- 身后青色弧线（环形）与两点星芒。
- 形象不做表情包、不做多姿势；只在空态、关于页、页脚小图标、侧栏四处出现。

### 与家族风格的偏离（已接受，写下来备查）

家族其他工作台是**扁平矢量圆胖机器人**（参考 `小肺宝logo.jpg`）。本台采用外部参考稿，属于 **3D 奶油渲染**体系，与家族不一致。偏离项：

| 项 | 家族规则 | 本台实际 | 处置 |
| --- | --- | --- | --- |
| 渲染风格 | 扁平矢量 | 3D 奶油 + 渐变 | 用户决定采用，接受 |
| 腮红 | 禁 | 有 | 用户决定采用，接受 |
| 盾牌 | 无 | 有 | 用户决定采用；**盾牌不得配「保护 / 预防 / 不得病」类文案**，否则构成疗效暗示 |
| 星芒 | 无 | 有 | 用户决定采用，接受 |
| 胸口橙心白圆牌 | 有 | 无（改为盾牌内人形 + 心） | 随参考稿 |

> 结论：**ATTR 台是家族里第一个不用扁平机器人体系的成员**。若日后家族要做统一视觉，本台是唯一需要重画的那个。

### 采用时做的两处修正

1. **中文全部本地重排**。参考稿的中文字形（`ATTR小甲宝`、副标题）本次实测是干净的，逐字放大核对无错笔；但它是 JPEG 有损压缩，文字边缘发虚，且字距不可调。因此副标题按原字号与位置用 PingFang SC Semibold 重排，字标保留原稿（清晰且无歧义）。
2. **副标题「公益AI助手」改为「患者记录助手」**。本台不是公益组织，「公益」会构成身份承诺；且与项目「只提供信息、不做诊断」的立场摩擦。**若确实要以公益身份运营，这一行可以改回，但需先确认资质与口径。**

## 6. 使用红线

1. 不把形象画成"患者"（不穿病号服、不躺床、不带输液管）——它是工具，不是病人。
2. 不用橙色做整体底色或大面积填充。
3. 品牌名不进医学文案：「小甲宝建议你……」这种句式一律禁止，品牌只在归属处出现。
4. 对外简介的第一句必须是病名，不是品牌名。
5. 「小甲宝」不得单独成句，出现处必须同时可见病名全称（对冲第 1 节保留意见第 1 条）。
6. 不把品牌包装成公益项目、不暗示资助关系、不做任何疗效或防护承诺。
7. **盾牌不得与「保护 / 预防 / 不得病 / 避免恶化」类文案同屏**——盾牌只作形象构件，不作功能承诺。
8. 形象不用于任何募捐、众筹、赞助鸣谢场景（未确认资质前不做）。
