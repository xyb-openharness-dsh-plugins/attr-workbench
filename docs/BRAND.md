### 为什么用「淀粉」

淀粉样变性患者的公开自称是**「淀粉人」**（2025-10-26 国际淀粉样变性日，澎湃新闻与腾讯新闻报道《终于找到你——赴一场"淀粉人"的生命之诺》，北京大学第一医院罕见病医学中心袁云教授同篇科普）。这个称呼来自"异常蛋白沉积像淀粉"的通俗解释，媒体、医生、病友三方都在用。

**但必须写清楚的一句**：ATTR 沉积的是**转甲状腺素蛋白（TTR）**，不是淀粉。品牌可以借用「淀粉人」这个共同体的词，页面文案不能把病名写成"淀粉沉积"。

### 已知风险（写下来，不藏）

1. **搜索冲突**：「淀粉宝宝」在中文搜索结果里被幼儿园课程（《你好！淀粉宝宝》）、婴儿辅食问答（《淀粉宝宝可以吃吗》）占满，自然流量为零，甚至会被误解成母婴内容。因此对外传播必须以「ATTR」「淀粉样变性」「心肌淀粉样变」为主关键词，品牌名只做识别。
2. **年龄错位**：ATTR 患者以 60 岁以上男性为主（野生型尤甚），"宝宝"对这部分人可能显得幼稚。缓冲办法：UI 里品牌只出现在侧栏与页脚，不进入提示语、按钮、表单，**不要出现"宝宝帮你……"这类拟人句**。
3. **家族命名节奏**：家族其他工作台是三字格（小畅宝 / 小胃宝 / 小咽宝 / 小莲宝 / 小胰宝），本台是四字且「宝」重复。这是刻意选择，不是笔误。

## 5. 生成与调色记录

- 形象由图像模型生成，提示词已固定为：对称正面、白脸、双眼一笑、无腮红无鼻子、天线实心球无光晕、胸口白圆牌 + 橙心、纯白底、无文字。
- 模型给出的机身青绿为 `#226967`，与品牌色 `#2E6E7E` 有偏差；**调色在本地做**：仅对青色相像素做 +16° 色相、饱和 ×0.92，其余像素不动。脚本逻辑见本节下方，重做时照抄即可。
- **文字一律本地排版**（PingFang SC Semibold），不让模型生成中文字形——模型生成汉字必然出错，且无法校准字距。

```python
# 调色关键三行（HSV 域内只动青色）
h, s, v = colorsys.rgb_to_hsv(r/255, g/255, b/255)
if 0.42 < h < 0.56 and s > 0.18:                 # 青色系
    h = (h + 0.045) % 1.0                        # +16°
    s *= 0.92
```

## 6. 使用红线

1. 不把形象画成"患者"（不穿病号服、不躺床、不带输液管）——它是工具，不是病人。
2. 不用橙色做整体底色或大面积填充。
3. 品牌名不进医学文案：「淀粉宝宝建议你……」这种句式一律禁止，品牌只在归属处出现。
4. 对外简介的第一句必须是病名，不是品牌名。
