## 4. 关键药物卡片

> 规则：机制未披露就写"未披露"；登记节点 ≠ 临床结果；疗效数字本工作台不摘录，只给"看哪篇原文"。**每张卡都不是用药建议。**

### 4.1 氯苯唑酸（tafamidis，维万心®，61 mg）

| 项 | 内容 |
| --- | --- |
| 属性 | 小分子 TTR 四聚体稳定剂；口服软胶囊，每日一次，随餐 |
| 治疗原理 | 与 TTR 四聚体结合，降低解离速率，减少错误折叠单体与淀粉样纤维生成；不清除已沉积的淀粉样物 |
| 研发阶段 | 已上市。关键试验 ATTR-ACT（NCT01994889）；中国 2020-09 获批 ATTR-CM（野生型与遗传型），2021 年进入国家医保 |
| 已发布数据 | ATTR-ACT 结果发表于 NEJM 2018（全因死亡与心血管住院复合终点）；**具体数值请回溯原文，本工作台不摘录** |
| 注意 | 说明书信息与剂量调整由医生决定；本工作台只记录"你在吃什么、从哪天开始、有没有停" |

### 4.2 氯苯唑酸葡胺（tafamidis meglumine，维达全®，20 mg）

| 项 | 内容 |
| --- | --- |
| 属性 | 同上机制，剂型/剂量不同；口服 |
| 治疗原理 | 稳定 TTR 四聚体 |

### 4.3 patisiran（Onpattro®）

| 项 | 内容 |
| --- | --- |
| 属性 | siRNA；脂质纳米颗粒静脉输注，每 3 周一次 |
| 治疗原理 | 靶向 TTR mRNA，经 RNAi 降低肝脏 TTR 生成（降幅见原文），减少底物供应 |
