# 用户与场景研究 · ATTR

日期：2026-10-21。**证据等级**：本文分「公开资料」「家族既有工作台经验」「待访谈假设」三类，混着写会在 G1 被当成已确认需求。

## 1. 服务谁（三个主体，不是一个人）

| 主体 | 他们此刻的状态 | 最需要的一句话 | 工作台给什么 |
| --- | --- | --- | --- |
| 已确诊的 ATTR-CM 患者（多为 60 岁以上男性，野生型居多） | 心衰反复、活动耐量下降、多次被当"高血压心脏病" | "我不是心衰没治好，我是另一种病" | 型别卡 + 心脏线 + 用药史 + 复诊准备 |
| 已确诊的 ATTRv-PN 患者（发病更早，常有家族史） | 脚麻、腹泻便秘交替、站起来头晕、体重掉 | "这些不是我想多了" | 神经线 + 自主神经 + 家系页 |
| 家系成员 / 照护者（配偶、子女） | 要陪着看病、要决定自己查不查 | "我能做什么、要不要查" | 级联筛查清单 + 可照着说的短句 |

**不服务**：尚未被怀疑 ATTR 的普通心衰人群（不做筛查工具，避免把工作台变成自诊器）。

## 3. 家族既有工作台经验（可复用，不必重证）

- **患者会拿手机拍报告**，不会扫描；录入必须允许"只填一个数 + 日期"。
- **一图秀是唯一会被反复打开的页面**，其余页面是"门诊前一周才打开"。
- **"我的看法"必须标注"不是医生结论"**，否则会被当成医嘱转发到家族群。
- **空态要写成"还没记录"**，不能写"无异常"。
- 罕见病用户对"登记 ≠ 可用"极其敏感，试验页必须每行带状态与来源。

## 6. 不做的事（研究结论，不是懒）

- 不做"我是不是 ATTR"自测问卷：ATTR-CA 可能性评分是医生的工具，患者自算会把 62% 特异度读成确诊。
- 不做家系风险百分比：常显遗传的 50% 是教科书数字，但对具体家庭是"要不要告诉孩子"的情绪问题，数字帮不上忙。
- 不做饮食处方：低盐是常识级建议，具体克数应由医生/营养师给。
