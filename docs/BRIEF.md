# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：转甲状腺素蛋白淀粉样变性（ATTR-CM / ATTRv-PN）患者、家系成员与照护者

场景：从心衰、腕管综合征、周围神经病等线索走到确诊（核素扫描 + 轻链排除 + 基因检测）；区分野生型与遗传型；记录心脏与神经两条受累线；长期使用稳定剂或基因沉默药物；家系级联筛查与复诊准备

核心流程：
1. 选择本机资料目录并导入检验、心超、核素扫描、基因报告
2. 核对候选信息，建立型别（野生型/遗传型）与表型档案
3. 记录 NT-proBNP、eGFR 等指标与心脏、神经症状序列
4. 登记用药方案、剂量调整与耐受情况
5. 生成家系筛查与复诊准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：型别与基因记录、心脏与神经受累序列、用药与耐受记录、家系筛查名单与复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
