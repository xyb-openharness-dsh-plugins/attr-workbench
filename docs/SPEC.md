## 1. 目标与非目标

**目标**：让 ATTR 患者、家系成员与照护者回答五个问题：

1. 我到底是**野生型还是遗传型**？基因报告上写的是什么？（**型别**）
2. 心脏受累到哪一步？神经受累到哪一步？（**两条受累线**）
3. 现在用的药是什么机制、什么时候开始、有没有停过、为什么停？（**治疗与耐受**）
4. 家里谁需要去查？我该怎么跟他说？（**家系与遗传**）
5. 下次门诊带什么、问什么？（**就诊准备**）

**非目标**：不做诊断、不做分期判定、不给用药建议、不判断能不能停药、不推荐医院与医生、不预测生存期、不做病友匹配、不做基因报告解读（只抄原文与医生结论）。

## 2. 产品立场

继承家族 9 条（见样板 SPEC §2），ATTR 补充：

10. **型别是两条不同的病**：野生型（ATTRwt）与遗传型（ATTRv）分开建档，绝不合并成"淀粉样变"。野生型档案不显示基因位点表，遗传型档案必须显示基因原文与检测机构。
11. **心脏与神经是两条平行线，不互相折算**：心脏用 NYHA / NT-proBNP / 心超；神经用 FAP 分期（医生给）/ 自查症状。不把"神经重"换算成"心脏轻"，也不给综合评分。
12. **家系信息是最高敏感级**：默认折叠、默认不导出、默认不进 AI 上下文；每个成员的检测状态由本人或家属自己填，工作台不推断谁"应该"是携带者。
13. **"无治愈"要写在明面上**：现有治疗目标是延缓沉积与延缓进展；不写"治好""逆转"，也不写"没救了"。这条同时约束字段命名（`delay` 而非 `cure`）。

## 3. 范围（一期，12 个一级页）

| # | 模块 | 内容 | 为什么 ATTR 需要 |
| --- | --- | --- | --- |
| 1 | 看板 | 定调条 →「现在可以做」→ 型别卡 → 心脏/神经双状态卡 → 用药卡 → 接下来 | 首屏要能回答"我是什么型、两条线各到哪" |
| 2 | 病情整理 | 资料库 / 草稿核对 / 病情档案 / 指标检测 / 病情汇总 | 家族通用骨架，四层事实不合并 |
| 3 | **我的分型** | 型别与基因 / 表型与分期 / **确诊路径** / 会诊与二次意见 | ATTR 确诊是一条链（PYP + 轻链 + 基因），链上每一步都要留原文 |
| 4 | 治疗历程 | 当前方案 / 用药与耐受 / 治疗调整史 / 支持治疗 | 稳定剂 vs 基因沉默 vs 支持治疗，机制不同、监测不同 |
| 5 | **心脏受累** | 心衰症状与体征 / 心超与影像 / 心律与晕厥 / 血压与用药耐受 | ATTR-CM 的主战场；低血压不耐受是特征性难题 |
| 6 | **神经与自主神经** | 感觉与运动 / 自主神经 / 腕管与脊柱 / 跌倒与安全 | ATTRv-PN 与 ATTRwt 都常有神经线索 |
| 7 | 检查与指标 | NT-proBNP 与肌钙蛋白 / 肾功能与电解质 / 血常规与肝功 / 影像与基因报告 | 指标决定分期与用药监测 |
| 8 | 病情一图秀 | 数值曲线 / 事件与节点 / 数据口径 | NT-proBNP + eGFR 双序列 + NYHA 分类节点 |
| 9 | **家族与遗传** | 家系图 / 级联筛查 / 遗传咨询记录 | 常染色体显性，一级亲属风险高；这是患者最常问、最难开口的事 |
| 10 | 生活与照护 | 饮食与体重 / 活动与康复 / **情绪与照护者** / 出行与资源 | 低盐、体位性低血压防护、跌倒、长途出行；情绪与照护者承担「话往哪放」——不做量表、不打分 |
| 11 | 复诊准备 | 复诊节奏 / 就诊准备 / 与医生讨论的问题 | 罕见病门诊时间短，准备材料决定沟通质量 |
| 12 | 临床研究 | 2026 线索 / 已收藏 / 入组问题 | 登记 ≠ 可入组；只给线索与问题 |

### 明确不做

基因变异致病性判读、用药选择与剂量建议、停药/减量建议、"是否需要 ICD"判断、生育决策建议、家系成员风险百分比计算、生存期预测、医院/医生推荐。

## 6. 验收

| # | 条目 |
| --- | --- |
| A1 | 野生型档案不出现基因位点表；遗传型档案必须显示基因原文、检测机构、报告日期 |
| A2 | 型别切换只新增记录，不覆盖旧记录（历史型别留痕） |

| A7 | 家系成员默认折叠，页面明写"由本人或家属填写，工作台不推断" |
| A8 | 一图秀双数值线 + 分类节点，分类节点不连线 |
| A9 | 所有试验条目带来源与"登记状态，未核实" |
| A10 | 全站不出现"治愈/逆转/生存期/建议用药/可以停药" |
| A11-A18 | 家族通用：版本同源、页脚贴底、页签穷举、AI 五态、字号三档、无溢出、控制台 0 error |
| A19 | 「生活与照护」与「复诊准备」职责边界常驻说明，防重复录入 |
| A20 | 野生型档案的「家族与遗传」显示"野生型一般不遗传"的说明，而不是空白 |

## 7. 风险

- **型别混淆**：野生型患者看到"家族筛查"会恐慌 → A20 常驻说明。
- **基因报告过度解读**：用户会追问"这个变异严重吗" → 页面固定一句"变异致病性由医生与遗传咨询判断"。
- **"无治愈"表达**：既要诚实又不能击垮 → 统一写"现有治疗目标是延缓沉积与进展"。
- **双线数据负担**：心脏+神经都要记，容易放弃 → 看板只要求每线 1 个核心指标，其余可选。

## 8. 术语

ATTR：转甲状腺素蛋白淀粉样变性；ATTRwt：野生型；ATTRv：遗传型（变异型）；ATTR-CM：心肌受累；ATTR-PN：多发性神经病；PYP：99mTc-焦磷酸盐骨闪烁扫描（Perugini 0–3 级）；sFLC：血清游离轻链（含 κ/λ 比值）；NT-proBNP：N 末端 B 型利钠肽原；eGFR：估算肾小球滤过率；NYHA：心功能分级；FAP：家族性淀粉样多发性神经病分期；TTR：转甲状腺素蛋白；siRNA/ASO：小干扰 RNA / 反义寡核苷酸（减少 TTR 生成）。
