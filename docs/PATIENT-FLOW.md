# 患者流程 · 小淀宝 AmyPal

日期：2026-10-21。依据：公开诊疗路径（中国 ATTR-CA 专家共识、PYP 判读标准、ATTR 药物说明书信息）+ 家族既有工作台的患者侧观察。**没有做真实患者访谈**，本文所有"患者最难受的时刻"是待验证假设，标注为〔待访谈核实〕。

## 0. 三条主线（页面树由这三条反推，不从医生流程照搬）

| 线 | 起点 | 患者最难受的时刻 | 打开哪一页 | 得到什么产物 |
| --- | --- | --- | --- | --- |
| L1 一次确诊 | 心衰/脚麻/腕管术后，多年没名字 | "查了这么久，到底是不是这个病？还要查什么？" | 我的分型 → 确诊路径 | 四步检查的完成状态 + 还缺哪一步 + 报告原文 |
| L2 一次复查 | 已在用药，3–6 个月一次门诊 | "这次指标是不是变差了？要不要换药？" | 看板 → 一图秀 → 复诊准备 | 双线趋势 + 三张要问的问题 |
| L3 一次家事 | 确诊遗传型，要告诉兄弟姐妹/子女 | "我要不要跟他们说？说了他们能做什么？" | 家族与遗传 → 级联筛查 | 家系名单（本人填）+ 一句可复制的话 |

## 1. L1 一次确诊（从线索到名字）

```
体检/心超发现室壁厚（或腕管术后多年、脚麻、站起来头晕）
   ↓ 患者自己搜到"淀粉样变"，信息碎片化：AL / ATTR / 野生型 / 遗传型 分不清
【触发】第一次被怀疑 ATTR → 医生开 PYP + 血尿免疫固定电泳 + 游离轻链
   ↓ 报告一堆：Perugini 2 级 / 3 级、κ/λ 比值、M 蛋白阴性——看不懂哪个是关键
【动作】在「我的分型 → 确诊路径」把四步逐条落位：
        ① 警示征（室壁厚 ≥12mm、低电压、腕管、脊柱狭窄…）
        ② 99mTc-PYP（0–3 级，原文抄）
        ③ 轻链与免疫固定电泳（阴性/阳性，原文抄）
        ④ TTR 基因检测（做/没做/等结果；做了就抄变异原文）
   ↓ 发现自己缺第三步 → 这条就是下次门诊要问的
【产物】确诊路径时间线 + 缺口清单 + 「就诊准备」里自动带入的三个问题
```

**设计要点**：四步都可"未做"，**空不等于阴性**（A5）。患者最常见的误解是"PYP 阳性就是确诊"，页面只呈现"医生据此写了什么"，不写我们的判断。

**〔待访谈核实〕**：真实患者是否知道"轻链必须排除"这一步；是否有人被直接告知"你是淀粉样变"却不知道分型。

## 2. L2 一次复查（3–6 个月门诊）

```
门诊前 3 天，拿到一批化验：NT-proBNP、肌酐/eGFR、肌钙蛋白、血常规
   ↓ 患者最难受的时刻：数字比上次高，但不知道高多少算"变差"
【动作】在「检查与指标」逐条录入（来源写报告名）
        在「病情一图秀」看 NT-proBNP 与 eGFR 同框：一个升、一个降
        分类节点（NYHA）只落在医生写的那次，不自己判
   ↓ 想起"上次说脚麻加重了""上个月站起来晕过一次"
【动作】在「神经与自主神经」补两条自查；在「心脏受累 → 血压与用药耐受」补一条
【产物】「复诊准备」生成一页：本次变化 3 条 / 想确认的事 3 条 / 正在用的药与起止
```

**设计要点**：一图秀默认只放 NT-proBNP + eGFR 两条线（数值），第三条是 NYHA（分类，不连线）。**为什么不放肌钙蛋白**：它长期低水平升高是特征，但波动小，和 NT-proBNP 同图会压平趋势。

## 3. L3 一次家事（遗传型确诊后）

```
基因报告回来：TTR 变异阳性 → 医生一句"这个会遗传"
   ↓ 患者最难受的时刻：要不要告诉兄弟姐妹/子女？他们会不会怪我？孩子要不要查？
【动作】打开「家族与遗传」：
        · 第一屏不是家系图，是一句"常染色体显性遗传，一级亲属也可能携带；是否检测由本人与医生决定"
        · 家系成员由患者自己添加（关系、是否已知、是否已检测），默认折叠
        · 记录遗传咨询的时间、机构、医生原话
【产物】一份"可以照着说"的短句 + 成员清单（可打印，默认不含基因结果细节）
```

**设计要点**：不计算风险百分比（A7）；不生成"建议检测"的祈使句；野生型档案这一页显示"野生型一般不遗传"而不是空白（A20）。家系数据默认不进 AI 上下文（SPEC 立场 12）。

## 4. 页面树（由三条线反推）

```
看板 ────────────── L2 入口（双线状态 + 下次门诊）
病情整理 ────────── L1 入口（把报告变候选，再变记录）
我的分型 ─┬ 型别与基因 ── L1/L3
          ├ 表型与分期 ── L2
          ├ 确诊路径 ──── L1 主战场
          └ 会诊与二次意见
治疗历程 ─┬ 当前方案 / 用药与耐受 / 治疗调整史 / 支持治疗 ── L2
心脏受累 ─┬ 心衰症状与体征 / 心超与影像 / 心律与晕厥 / 血压与用药耐受 ── L2
神经与自主神经 ─ 感觉与运动 / 自主神经 / 腕管与脊柱 / 跌倒与安全 ── L1/L2
检查与指标 ── L2 数据入口
病情一图秀 ── L2 主视图
家族与遗传 ── L3 主战场
生活与照护 ── L2 间隙（低盐、体位性低血压、跌倒）
复诊准备 ──── L2 出口
临床研究 ──── L1 之后（确诊后才会问"有没有新药"）
```

## 5. 三个反推结论（决定了页面边界）

1. **「确诊路径」必须是独立子页，不能塞进"病情档案"**：L1 阶段患者还没有"档案"，只有一条检查链。
2. **「家族与遗传」必须是一级页，不能放在"设置"里**：L3 是情绪事件，不是一个配置项。
3. **「生活与照护」不设"饮食处方"**：低盐与体重是自我记录，具体摄入由医生/营养师给。这一页只记"我吃了什么、体重多少、站起来晕不晕"。

## 6. 尚未验证的假设（进 G1 时要问用户）

| # | 假设 | 验证方式 |
| --- | --- | --- |
| H1 | 患者分得清"野生型/遗传型"，但不知道"野生型不遗传" | 访谈 3 位 ATTR-CM 患者 |
| H2 | 复查时最想看的是 NT-proBNP，而不是心超射血分数 | 访谈 + 看患者手机里存了哪些报告 |
| H3 | 家系沟通是确诊后 1 个月内最高频的困扰 | 病友组织访谈 |
| H4 | 用药耐受（头晕、腹泻、注射部位反应）比疗效更影响依从 | 访谈用维持剂量的患者 |
