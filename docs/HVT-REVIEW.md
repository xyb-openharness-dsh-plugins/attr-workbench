- 疾病轴：ATTR 在十条轴上与既有五个样板的差异，见 `DIFF-MATRIX.md` 第一张表（型别 × 表型 2×2、无 TNM、无分子分型、无手术、双器官线）。
- 打分：V（价值）S（可行）F（频次）各 1–3；HVT 门槛 V≥2 且 S≥2；优先级 P = V×S×(5−C)，C = 1 已有能力 … 4 缺一整层。
- 五层：S 场景 / M 模块 / F 字段 / I 交互 / A 验收，各 0 或 1。
