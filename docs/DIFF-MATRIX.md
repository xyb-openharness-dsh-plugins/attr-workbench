# 差异矩阵 · ATTR vs 家族样板

日期：2026-10-21。对照对象：`esophageal-workbench v0.1.0`（最近一次跑通 ZERO-TO-DEV 的癌种样板）、`gastric-workbench v0.1.0`、`fshd-workbench`（非肿瘤慢病形态）。

**用途**：防"换名癌种"。每一行都要能回答"为什么这一页/这张表/这个字段 ATTR 必须有，而样板没有"。**没有理由的差异一律删掉，回到样板。**

## 1. 疾病形态差异（决定结构，不只是文案）

| 维度 | 食管癌样板 | ATTR | 结构后果 |
| --- | --- | --- | --- |
| 疾病性质 | 恶性肿瘤，分期驱动治疗 | 系统性沉积病，**型别 + 两条受累线**驱动 | 一级页从"治疗路径"改为"分型 + 心脏 + 神经"三足 |
| 治愈性 | 有根治性治疗（手术/放化疗） | **无治愈**，治疗目标是延缓沉积与进展 | 全站禁"治愈/逆转"；字段名用 `delay` |
| 遗传 | 少数遗传易感 | **常染色体显性**（ATTRv），一级亲属风险高 | 独立一级页「家族与遗传」，家族通用模块没有 |
| 病程 | 以月/疗程计 | 以年计，长期用药与耐受 | 用药史按"方案段"管理，而非"周期" |
| 关键检查 | 胃镜、病理、SCC-Ag | PYP 核素、轻链、基因、心超、NT-proBNP | 「确诊路径」四步链；无肿瘤标志物 |
| 主体 | 患者本人 | 患者 + **家系成员**（未发病者） | 家系成员是数据主体，但不是"第二个档案" |

## 2. 页面级差异

| 样板页 | ATTR 处理 | 理由 | 不许怎样 |
| --- | --- | --- | --- |
| 我的分型（病理/分段/分期） | 改为**型别与基因 / 表型与分期 / 确诊路径 / 会诊** | 没有"病理类型"，只有 TTR 变异与否 | 不许把"鳞/腺"改名成"野生型/遗传型"就算完成——基因原文、检测机构、报告日期是新增字段 |
| 治疗历程（路径三选一） | 改为**方案段**：稳定剂 / 基因沉默 / 支持治疗，可并行 | ATTR 常见"稳定剂 + 支持治疗"同时用，不是三选一 | 不许保留"路径三选一"的单选结构 |
| 吞咽与进食通路 | **删除** | 无吞咽通路问题；进食相关只有"低盐/体重" | 不许换成"饮食通路"占位 |
| 营养支持 | 合并进「生活与照护 → 饮食与体重」 | 营养不是主战场，不设独立页 | 不许保留两个营养入口 |
| 检查与指标（体重/白蛋白/标志物/内镜） | 改为 **NT-proBNP/肌钙蛋白 / 肾功能电解质 / 血常规肝功 / 影像与基因** | 指标组完全不同 | 不许留"肿瘤标志物"空壳 |
| 复诊准备（胃镜+第二原发监测） | 改为**复诊节奏 / 就诊准备 / 与医生讨论的问题** | 无第二原发监测概念 | 不许把"第二原发"换成"并发症监测"含糊带过 |
| — | **新增「心脏受累」** | ATTR-CM 是主要死因，症状/心超/心律/血压耐受四块 | 不许并进"检查与指标"——那是数据，这是状态 |
| — | **新增「神经与自主神经」** | ATTRv-PN 与 ATTRwt 都常见；自主神经症状（体位性低血压、腹泻便秘、泌尿）是独立负担 | 不许只做"症状列表"，必须有自主神经分块 |
| — | **新增「家族与遗传」** | 遗传咨询与级联筛查是患者最高频的非医疗需求 | 不许放在设置里；不许算风险百分比 |

## 3. 与 FSHD（同为非肿瘤慢病）的差异

| 项 | FSHD | ATTR | 说明 |
| --- | --- | --- | --- |
| 治疗 | 无药，康复为主 | **有药**（稳定剂/基因沉默），需长期监测 | ATTR 的「治疗历程」比 FSHD 重得多 |
| 遗传 | 常染色体显性，多有家族史 | 同样显性，但**野生型占多数** | ATTR 的家族页必须处理"不遗传"的分支（A20） |
| 进展指标 | 功能量表、力量 | NT-proBNP、eGFR、NYHA、FAP | 一图秀双数值线 |
| 急性风险 | 低 | 心衰失代偿、晕厥、猝死风险（由医生评估） | 看板有"这次要问的紧急问题"位，但不给急诊判断 |

## 4. 数据层差异（详见 `docs/SCHEMA.md`）

| 表 | 样板有 | ATTR | 差异理由 |
| --- | --- | --- | --- |
| `swallow_rows` / `access_rows` / `dilation_rows` | 有 | **无** | 无吞咽通路语义 |
| `genotype_rows` | 无 | **有** | 基因变异原文 + 检测机构 + 报告日期 + 医生原话；野生型档案为空但保留"未检测"状态 |
| `phenotype_rows` | 无 | **有** | 表型（心脏为主/神经为主/混合）+ 起病年龄 + 首发症状 |
| `diagnosis_rows` | 无 | **有** | 四步确诊链，`state ∈ {done, not_done, pending}`，`not_done ≠ negative` |
| `cardiac_rows` / `echo_rows` | 无 | **有** | 心衰症状、NYHA（医生给）、心超参数、心律事件 |
| `neuro_rows` / `autonomic_rows` | 无 | **有** | 自查症状序列 + 自主神经分块；`self=1` 固定标注 |
| `redflag_rows` | 无 | **有** | 腕管/脊柱/肱二头肌腱/白内障，带"确诊前/后"标记 |
| `drug_rows` / `tolerance_rows` | `cycles` | **有** | 方案段 + 停换原因 + 耐受事件；不覆盖旧段 |
| `family_rows` / `counsel_rows` | 无 | **有** | 家系成员（`private=1` 默认）+ 遗传咨询记录 |
| `daily_rows` | `nutrition_rows` | **有** | 饮食/体重/活动/出行，无热量换算 |
| `monitor_rows` | 有 | **有**（复用） | 随访安排：心超、化验、基因复查 |
| `molecular` | 有 | **无** | 基因信息进 `genotype_rows`，不用肿瘤分子表 |

## 5. 刻意保留的家族共性（不许"为了不一样"改掉）

- 顶栏三段式、AI 五态（未进入/可用/生成中/折叠/降级）、25%–45% 可拖面板。
- 一图秀引擎常量（CW1000/CH420/CX0 62/CX1 954/CY0 132/CY1 366）、单调三次插值、末点 13px 避让、指标卡 186px 背面迷你折线。

### 一图秀偏离（唯一一处，CW 980 → 1000）

| 项 | 家族基线 | 本工作台 | 原因 |
| --- | --- | --- | --- |
| 画布宽 | 980 | **1000** | ATTR 是双纵轴（NT-proBNP 左 / eGFR 右），且 eGFR 单位 `mL/min/1.73m²` 有 13 个字符；980 宽时末点标签只能压在曲线末段上 |
| 末点标签位置 | 右端左锚定贴点 | 右侧 36px 槽内左锚定 | 让开右侧纵轴刻度，不压曲线 |
| 长单位处理 | 完整带单位 | 单位 > 6 字符时省略（单位留在左栏图例） | `980 pg/mL` 保留，`64` 只留数值 |

代价：画布更宽 → 同宽度下纵向高度略低，曲线看起来比样板"扁"一点；换图例可读性，可接受。若要回退，改 `app.js` 的 `CH.CW` 与末点标签 x 偏移即可。
- 字号三档、页脚贴底、`[hidden]{display:none!important}`、`apiBase` 不含 `/api`。
- 四条数据契约、迁移只增不改、版本唯一来源 `VERSION`。

## 6. 一句话自检

> 把这套页面里的 "ATTR" 换成 "食管癌"，还能跑吗？
> 不能——因为 PYP/轻链/基因四步链、心脏-神经双线、家系级联三块在食管癌里没有对应物；而食管癌的吞咽通路、SCC-Ag、第二原发监测在这里全部删除。**这就是差异，不是换名。**
